
# SmartSupport AI

An AI-powered customer support assistant that answers customer questions using company FAQ documents.

## Project Overview

SmartSupport AI uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from a knowledge base and generate helpful answers using a locally running language model.

## Technologies

- Python
- Ollama
- LangChain
- ChromaDB
- FastAPI
- Streamlit
- Docker

## Planned Features

- Load customer FAQ documents
- Generate text embeddings
- Store and retrieve information using ChromaDB
- Generate answers using Ollama
- Provide a REST API using FastAPI
- Build a chat interface using Streamlit

## Project Status

Currently under development.
